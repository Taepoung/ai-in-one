# 사용량 팝업

> 2026-10-20 리팩토링 §6 에서 문서를 에이전트별로 나눴다. **절 이름(§A · §F4 · §G6 …)은
> 옮기기 전 그대로**라 옛 링크(`PIN.md §G6` 같은)는 그 파일의 지도로 한 번 건너면 닿는다.
> 이 문서: 방 머리의 「사용량」 — 기능이라 core 다

어댑터마다 잔량이 어떻게 오는지(쓴 양 / 남은 양 · 명령 이름)는
`src/agents/README.md` 의 «토큰 한도» 에 셋을 맞대어 있다.

## 지었다 — 방 머리의 「사용량」

2026-10-19 에 붙였다. **참여자 서랍 아이콘 왼쪽**에 단추가 서고, 누르면
에이전트마다 한 줄씩 선 팝업이 뜬다. 새로고침이 다시 받아온다.

```
AcpConnection.probeUsage   조회용 세션을 열고 · /usage 를 한 번 묻고 · 닫는다
RoomManager.quotaOf        에이전트마다 (방이 쓰는 것만) · 하나가 터져도 나머지는 온다
protocol                   quotaAsk ↔ quota
webview                    단추 · 팝업 · 새로고침
```

🔴 **방을 안 거치는 것이 이 기능의 전부다.** `send` 로 보내면 읽던 대화에
말풍선이 둘 남는다 — 그래서 `tests/quotaui.mjs` 가 제일 세게 재는 것이
«눌러도 `send` 가 안 나간다» 이다.

★ **묶음은 에이전트다.** 잔량은 계정에 붙으므로, 한 방에 Claude 봇이 둘
있어도 **물어볼 것은 한 번**이다.

★ **뜯되, 참을 안 덮는다** (2026-10-19 늦게 고침). 처음엔 글만 세웠는데 —
퍼센트와 리셋 시각은 셋이 공통으로 주므로 **막대를 세울 수 있다.** 못 뜯으면
빈손이고, 받은 글은 **언제나 접어서 그대로** 남는다. 그래서 모양이 바뀌어도
잃는 것은 «막대» 하나고, 사람은 한 번 더 눌러 진짜 글을 본다.

🔴 **셋의 뜻이 같지 않다.** Claude 는 «얼마나 **썼나**», Codex·Antigravity 는
«얼마나 **남았나**» 를 준다 — 그대로 나란히 세우면 **3% 가 거의 다 쓴 것처럼**
보인다(정반대다). 화면은 **언제나 «남은 양»**(`QuotaLine.left`) 으로 맞춘다.

### 누가 무엇을 하나 — 코어는 꼴, 애드온은 뜯기

★ **코어는 에이전트를 모른다** (2026-10-20, 사용자: *«코어는 에이전트 종류
상관없이 처리하고 애드온이 어댑터로 그에 맞춰주는게»*).

```
애드온 (src/agents/<id>/quota.ts)   무엇을 물을지(commands) · 그 글을 뜯어 QuotaLine[] 으로
standard (src/agents/standard/)     처음 보는 에이전트 — 글을 보고 짐작한다
코어                                QuotaLine 이라는 꼴과 그 규칙(left 는 늘 남은 양 · 0~100)
                                    조회 세션 열기 · 화면
```

⏪ 처음(리팩토링 ③)엔 코어에 공통 파서 하나를 두고 애드온은 «명령 이름 · 쓴 양/
남은 양» 만 선언했다. 그러면 정규식 하나가 세 에이전트의 모양을 동시에 받는다 —
Codex 가 모양을 바꿔 그걸 고치면 **Claude·Antigravity 가 같이 깨질 수 있다.**
애드온으로 나눈 까닭을 정면으로 거스르는 꼴이라 뜯기를 통째로 애드온으로 옮겼다.
검사는 «한 애드온이 남의 글을 안 뜯는다» 까지 민다(`tests/quotaparse.mts`).

🔴 **애드온이 터져도 팝업은 산다.** 코어가 파서를 감싸 부른다 — 예외가 올라오면
그 에이전트 줄은 막대 없이 받은 글만 서고, 다른 에이전트 줄은 그대로다.

★ **원본은 늘 코어가 쥔다.** 애드온은 ACP 통로에 끼어들지 않는다 — 코어가 받은
글을 «이거 어떻게 읽어?» 하고 넘길 뿐이고, 뜯은 것은 **더해질 뿐** 받은 글을
갈아 끼우지 않는다.

⚠️ **깨져도 조용하다.** 그래서 `docs/BUMP.md` ⑮ 와 `docs/RELEASE.md` 0절에
«손으로 보는 것» 으로 적어뒀다 — 핀을 올릴 때와 **우리 판을 내보낼 때** 둘 다.

⚠️ **열 때마다 묻지 않는다.** 들고 있던 것을 먼저 보여주고 «언제 받은
것인지» 를 적는다. 열 때마다 물으면 팝업을 두 번 여는 것만으로 세션이
둘 뜬다(Antigravity 는 한 번에 20초다).

⚠️ **저쪽 디스크에는 세션이 하나 남는다.** `probeConfigOptions` 는 프롬프트를
안 보내서 기록이 아예 안 생기는데, 이쪽은 한 번 보내므로 남는다. 담긴 것은
`/usage` 한 줄이다.
